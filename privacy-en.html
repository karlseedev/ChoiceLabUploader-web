Choice Lab Uploader Privacy Policy

Last updated: October 2, 2026 | Effective: October 2, 2026

1. Overview

Choice Lab Uploader (the "Tool") is a command-line tool that the owner of the Choice Lab channel runs on their own computer to upload their own videos to their own YouTube channel. The Tool is used by one person, the channel owner, and is not offered to the public.

2. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, the user agrees to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

3. Information the Tool Accesses

The user signs in with their own Google Account and grants the Tool the following access:

AccessWhat the Tool does with it
Upload videos (youtube.upload)Uploads a video file chosen by the user, with the title, description, tags and visibility the user entered, to the user's own channel
View the YouTube account (youtube.readonly)Reads the name, ID and video count of the user's own channel, and the status of videos the user uploaded, to confirm which channel is connected and whether an upload finished

* The Tool does not access any other user's account, channel or data.

4. Information the Tool Stores

  • The OAuth access token and refresh token issued by Google are stored in a file on the user's own computer, readable only by that user.
  • Channel information and video status read from YouTube are shown on the user's screen and are not saved.
  • The Tool has no server. Nothing is sent to the developer or stored outside the user's computer.

5. How Information Is Used and Shared

  • Information is used only to upload the user's videos to the user's own channel and to confirm the result.
  • Information is not shared with, sold to or transferred to any third party.
  • Information is not used for advertising, analytics or profiling.

6. Cookies and Similar Technologies

The Tool does not use cookies, and does not place, access or recognize cookies or similar technologies on any device or browser. This website does not use cookies or analytics either.

7. Revoking Access and Deleting Data

  • The user can revoke the Tool's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions
  • Deleting the token file on the user's computer removes all stored authorization data.
  • Requests about data can also be sent to the contact below. A reply is given within 10 days.
