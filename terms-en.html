Choice Lab Uploader Terms of Use

Last updated: October 2, 2026 | Effective: October 2, 2026

1. Service Overview

Choice Lab Uploader (the "Tool") is a command-line tool that uploads videos to a YouTube channel through YouTube API Services. It is used only by the owner of the Choice Lab channel to upload their own videos to their own channel. It is not offered to the public.

2. YouTube Terms of Service

The Tool uses YouTube API Services. By using the Tool, the user agrees to be bound by the YouTube Terms of Service.

3. Usage Requirements

  • The user signs in with their own Google Account and may upload only to a channel they own.
  • The user may upload only videos they made or have the right to upload.
  • Uploaded videos must comply with the YouTube Terms of Service and the YouTube Community Guidelines.
  • The Tool must not be used for spam, bulk uploads of duplicate content, or any other use that the YouTube API Services policies prohibit.

4. Handling of Information

How the Tool handles information is described in the Privacy Policy. The Tool has no server and stores authorization data only on the user's own computer.

5. Revoking Access

The user can revoke the Tool's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions

6. Fees

The Tool is free. It has no paid features, advertising or subscriptions.

7. Disclaimer

  • The Tool is not affiliated with, sponsored by or endorsed by YouTube or Google.
