선택연구소 업로더 이용약관

최종 수정일: 2026년 10월 2일 | 시행일: 2026년 10월 2일

1. 서비스 개요

선택연구소 업로더(이하 "도구")는 YouTube API 서비스를 통해 YouTube 채널에 영상을 올리는 명령줄 도구입니다. 선택연구소 채널 운영자가 본인이 만든 영상을 본인 채널에 올리는 데에만 사용하며, 일반에 제공하지 않습니다.

2. YouTube 서비스 약관

도구는 YouTube API 서비스를 이용합니다. 도구를 사용하는 이용자는 YouTube 서비스 약관에 동의하는 것으로 봅니다.

3. 이용 조건

  • 이용자는 본인의 Google 계정으로 로그인하며, 본인이 소유한 채널에만 올릴 수 있습니다.
  • 이용자는 본인이 만들었거나 올릴 권리가 있는 영상만 올릴 수 있습니다.
  • 올리는 영상은 YouTube 서비스 약관과 YouTube 커뮤니티 가이드를 지켜야 합니다.
  • 도구를 스팸, 중복 콘텐츠 대량 업로드 등 YouTube API 서비스 정책이 금지하는 용도로 써서는 안 됩니다.

4. 정보 처리

도구가 정보를 다루는 방식은 개인정보처리방침에 적혀 있습니다. 도구에는 서버가 없으며, 인증 정보는 이용자 본인 컴퓨터에만 저장합니다.

5. 접근 권한 철회

이용자는 Google 보안 설정 페이지에서 언제든지 도구의 접근 권한을 철회할 수 있습니다: https://security.google.com/settings/security/permissions

6. 요금

도구는 무료입니다. 유료 기능, 광고, 구독이 없습니다.

7. 면책

  • 도구는 있는 그대로 제공됩니다. 네트워크 문제, API 한도, YouTube API 서비스의 변경으로 업로드가 실패하거나 늦어질 수 있습니다.
  • 도구는 YouTube 또는 Google과 제휴, 후원, 보증 관계가 없습니다.
