선택연구소 업로더 개인정보처리방침

최종 수정일: 2026년 10월 2일 | 시행일: 2026년 10월 2일

1. 개요

선택연구소 업로더(이하 "도구")는 선택연구소 채널 운영자가 자기 컴퓨터에서 실행해, 본인이 만든 영상을 본인의 YouTube 채널에 올리는 명령줄 도구입니다. 채널 운영자 한 사람만 사용하며, 일반에 제공하지 않습니다.

2. YouTube API 서비스 이용

도구는 YouTube API 서비스를 이용합니다. 도구를 사용하는 이용자는 YouTube 서비스 약관에 동의하는 것으로 봅니다. YouTube API 서비스를 통해 다루는 정보에는 Google 개인정보처리방침도 적용됩니다.

3. 도구가 접근하는 정보

이용자는 본인의 Google 계정으로 로그인해 도구에 다음 권한을 부여합니다.

권한도구가 하는 일
동영상 업로드 (youtube.upload)이용자가 고른 영상 파일을 이용자가 입력한 제목, 설명, 태그, 공개 범위와 함께 이용자 본인의 채널에 올립니다
YouTube 계정 보기 (youtube.readonly)이용자 본인 채널의 이름, ID, 영상 수와 이용자가 올린 영상의 상태를 읽어, 어느 채널에 연결됐는지와 업로드가 끝났는지 확인합니다

* 도구는 다른 이용자의 계정, 채널, 데이터에 접근하지 않습니다.

4. 도구가 저장하는 정보

  • Google이 발급한 OAuth 액세스 토큰과 리프레시 토큰을 이용자 본인 컴퓨터의 파일에 저장하며, 그 이용자만 읽을 수 있습니다.
  • YouTube에서 읽은 채널 정보와 영상 상태는 이용자 화면에 표시할 뿐 저장하지 않습니다.
  • 도구에는 서버가 없습니다. 어떤 정보도 개발자에게 전송되거나 이용자 컴퓨터 밖에 저장되지 않습니다.

5. 정보의 이용과 공유

  • 정보는 이용자의 영상을 이용자 본인 채널에 올리고 그 결과를 확인하는 데에만 씁니다.
  • 정보를 제3자에게 공유, 판매, 이전하지 않습니다.
  • 정보를 광고, 분석, 프로파일링에 쓰지 않습니다.

6. 쿠키 및 유사 기술

도구는 쿠키를 사용하지 않으며, 어떤 기기나 브라우저에도 쿠키나 유사 기술을 저장, 접근, 인식하지 않습니다. 이 웹사이트도 쿠키와 분석 도구를 사용하지 않습니다.

7. 접근 권한 철회와 데이터 삭제

  • 이용자는 Google 보안 설정 페이지에서 언제든지 도구의 접근 권한을 철회할 수 있습니다: https://security.google.com/settings/security/permissions
  • 이용자 컴퓨터의 토큰 파일을 지우면 저장된 인증 정보가 모두 삭제됩니다.
  • 데이터에 관한 요청은 아래 연락처로도 보낼 수 있으며, 접수 후 10일 이내에 답변합니다.
